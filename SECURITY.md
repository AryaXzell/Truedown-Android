# Security Policy

## Supported Versions

Security updates and bug fixes are provided for the latest release of Truedown Android.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security and integrity of Truedown seriously.

### How to Report
Please report suspected vulnerabilities by opening a new issue in our [GitHub Issues](https://github.com/aryaxzell/truedown-android/issues) tracker.

> :warning: **Important Public Notice:**
> Because GitHub Issues are publicly visible, **DO NOT** include:
> - Exploitation scripts or executable payloads.
> - Private tokens, signing keys, passwords, or personal credentials.
> - Personal identifiable information (PII).
>
> Please provide a high-level summary of the issue, the affected components, and the potential impact. If additional private details are required, maintainers will provide a secure communication channel.

---

## What Qualifies as a Security Vulnerability?

Examples of issues that should be reported include:
- Insecure media transmission or improper certificate handling.
- Accidental exposure of signing keys or build secrets.
- Arbitrary file write or traversal vulnerabilities during media extraction.
- Malicious tampering of APK packaging or distribution artifacts.
